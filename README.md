# Sentix — Sentiment Analysis Web App 🧠💬

**Sentix** is a full-stack sentiment analysis web application that lets users analyze the sentiment of text (e.g., positive, negative) using a trained Python model. The app is built with **Flask**, served via **Gunicorn**, and deployed on **Azure App Service** using **GitHub Actions CI/CD**.

---

## 🚀 Features

- 🔍 Analyze sentiment of text input in real time  
- 🧠 Powered by a custom Python sentiment model  
- 🌐 Hosted and deployed automatically on Azure  
- 📦 Static assets included (CSS, images)  
- 💡 CI/CD pipeline with GitHub Actions
